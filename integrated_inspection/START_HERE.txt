Menu option5 mein included training examples par software demo chalta hai.

ACTUAL LIMITS

Inhe reliable material sorting mat samajhna. Camera data se improvement chahiye.
Independent detector/classifier disagree karein toh screen par Material check: unsure aata hai.

Tumhare CCTV camera ki testing abhi nahi hui hai.

MATERIAL + SCRATCH / DEFECT INSPECTION

1. RGB PHOTO
   RUN_PHOTO.bat par photo drag-drop karo, ya double-click karke photo ka
   full path paste karo. Spaces wale paths supported hain.
   Material boxes/classification aur aluminium defect boxes/masks chalenge.
   Annotated results aur report outputs\rgb_photo mein milenge.

2. NIR CAMERA PHOTO
   Actual NIR camera image ke liye RUN_NIR_PHOTO.bat use karo.
   Is mode mein NIR material model chalega; RGB defect model skip hoga.
   Results outputs\nir_photo mein milenge.

3. LIVE CAMERA (sirf jab tum launch karo)
   RUN_WEBCAM.bat: RGB camera 0.
   RUN_DUAL_CAMERA.bat: RGB camera 0 aur NIR camera 1.
   Camera window mein Q ya Esc se band karo.
   Dual-camera views alag panes hain; calibration/registration nahi hai.
   Ek camera ki box position ko doosre camera par sahi mat samajhna.
   Agar camera indices alag hain, neeche wali command mein 0/1 badal do.

PYTHON SETUP
   Launchers folder ke andar, parent, aur grandparent mein .venv_gpu pehle
   aur .venv baad mein dhoondhte hain. Activation zaroori nahi hai.
   GPU available aur usable hua toh --device auto usko choose karega.
   Naye computer par SETUP_WINDOWS.bat se Python 3.11 CPU setup banao.
   Ye setup NVIDIA/CUDA installer nahi hai. Internet chahiye.

POWERSHELL COMMANDS (is integrated_inspection folder ke andar se)
   Actual project ka GPU environment do levels upar ho toh:

   ..\..\.venv_gpu\Scripts\python.exe .\run_inspection.py --source "C:\photos\sample image.jpg" --input-mode rgb --output ".\outputs\rgb_photo" --show --device auto

   ..\..\.venv_gpu\Scripts\python.exe .\run_inspection.py --source "C:\photos\nir sample.png" --input-mode nir --output ".\outputs\nir_photo" --show --device auto

   ..\..\.venv_gpu\Scripts\python.exe .\run_inspection.py --source 0 --nir-source 1 --output ".\outputs\dual_camera" --show --device auto

   Portable CPU setup use kar rahe ho toh Python path ko
   .\.venv\Scripts\python.exe se replace karo.
